# Junior Astronaut Mission Trainer

## Run locally

1. Open this folder in VS Code.
2. Open Terminal.
3. Run:

```bash
npm install
npm run dev
```

4. Open the localhost URL shown by Vite.

## Prototype features

- Moon + Mars missions
- Isometric-style 3D outpost
- Rotatable/zoomable scene
- Astronauts and rover
- Oxygen, power, food, water, shielding and crew-health systems
- Clickable outpost systems
- Building/upgrade system
- Day progression
- Mission events with trade-offs
- Science score
- Mission success/failure
- Mobile-responsive UI

## Important

The current version is a functional prototype. Resource formulas and event consequences are intentionally simplified educational mechanics. NASA APIs/data are not yet connected. Before submitting to NASA Space Apps, integrate and cite real NASA sources such as DONKI, OSDR/RadLab and planetary datasets, and clearly distinguish real data from simulated gameplay.
